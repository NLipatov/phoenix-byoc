# Generic agent input delivery v1

This is a public source-level transport contract, not release or image certification. Runtime preparation/delivery, recovery fences, privacy and Agents marker integration are implemented in source. Compatible deployment, exact-image verification and native capability admission remain separate gates. No production image is certified by these fixtures.

`sourceRevision` is the Git HEAD immediately before authoring this export (a reproducible lineage anchor), **not** the commit containing exported bytes. Manifest hashes identify exact checked-in bytes. Re-export only after an intentional source/contract revision; a future change should update this provenance anchor.

Policy admission checks the trusted execution enterprise before reading values; each load uses one projected generation. Secrets are byte-preserved; collisions reject even identical/empty existing values. Only named error codes are public. Unsupported targets include Windows, external-host and lab. Unrelated legacy inputs remain unchanged. The PHOENIX_AGENT_SECRET_ prefix belongs only to projected filenames: runtime delivery injects the exact destination env name plus PHOENIX_AGENT_SECRET_NAMES_JSON, a sorted names-only array. The generic fixture exports that exact flat environment for unchanged consumer tests. Engine does not interpret named provider configuration: Agents owns native runtime/capability admission. Source-level integration and offline tests do not authorize activation.
